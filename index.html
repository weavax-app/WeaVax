Política de Privacidad y Protección de Datos

En WeaVax (weavax.link y app móvil com.Arax.LifeOs), tus datos financieros, cuentas, transacciones, tareas y notas personales se almacenan de forma privada bajo tu cuenta autenticada mediante Firebase Authentication y Cloud Firestore, y nunca se venden ni comparten con terceros o redes publicitarias.

En el módulo opcional de Comunidad Fitness, únicamente se muestran los datos que tú decides hacer públicos en public_profiles (nombre, @usuario, nivel y entrenamientos publicados). Puedes modificar tus ajustes de privacidad o eliminar tu cuenta y todos tus registros en cualquier momento desde la sección Ajustes.

Uso de Google Calendar API y Condiciones del Servicio

El uso y la transferencia de información recibida de las API de Google por parte de WeaVax cumple con la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado. Solicitamos acceso exclusivamente al alcance https://www.googleapis.com/auth/calendar.events para sincronizar bidireccionalmente los eventos y recordatorios que creas en tu agenda.

WeaVax se proporciona como herramienta de organización personal y seguimiento deportivo. Para soporte, solicitudes de eliminación de datos o consultas sobre WeaVax Pro, contáctanos en @weavax.app.
